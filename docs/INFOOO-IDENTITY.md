# INFOOO — Interactive Knowledge Worlds

**Role:** UNDERSTAND  
**Tagline:** See it. Touch it. Understand it.  
**Mission:** Turn difficult knowledge into something people can explore.

Infooo lets people experience why things work. It is curious, observant, clever, simple in explanation, and never condescending. Its visual identity is `#5CCFAF` with the existing `infooo.png` mascot.

## Design contract

- Show before explaining. Interaction must improve understanding.
- Objects matter; relationships teach. Complexity unfolds gradually.
- Use simple words for deep ideas. A visitor should leave knowing something new.
- It is not a static infographic gallery, prettier Wikipedia, a generic 3D viewer, calculator, textbook, random animation, AI trivia, or decorative 3D.

The experience loop is **See → Explore → Isolate → Connect → Understand**. A world declares only useful interactions: Explore, Isolate, Layer, Explode, Animate, Compare, Timeline, Simulate, What If?, Connect, Focus, and Reset. Optional modes are Explore, Guide Me, What Happens If?, and Compare.

Every world should answer, briefly: what it is, where it is, how it works, what it connects to, and why it matters. Relationships are first-class data: entity → relationship → entity → explanation.

## Truth, accessibility, and performance

Truth distinguishes **Fact** (authoritative source), **Model** (Khizooology simplification), and **Simulation** (interactive behavior). Sources, limitations, educational context, and review dates render only when real information is present.

Worlds provide semantic controls, keyboard-operable entity lists, searchable objects, textual selected knowledge, visible focus, non-color-only connections, and reduced-motion support. Mobile keeps the stage dominant, with touch-first selection and compact controls.

“Load the world, not the universe.” Future worlds should lazy-load assets, use progressive loading and optimized media, cache safely, and move heavy processing to workers where useful.

## Candidate and Value Laws

An Infooo candidate passes only when text alone is insufficient, relationships/processes matter, interaction improves comprehension, visualization can be accurate, a mental-model gap exists, and factual knowledge can be sourced. An aha moment is desirable. It uses the shared Value Laws, emphasizing Truth, Depth, Visuality, Interaction, Clarity, Utility, and Original Contribution.

## Current world and future rule

- **World 001 — Human Atlas:** published as Infooo’s current public world.

Future worlds are added only after a real idea passes Truth, accessibility, performance, and the Khizooology Value Laws. Infooo does not need multiple worlds simply to grow the count. A world is added only when the idea deserves to exist. Quality over quantity.
