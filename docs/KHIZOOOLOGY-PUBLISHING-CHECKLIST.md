# Khizooology Publishing Checklist

| Area | Check |
|---|---|
| VALUE | Score the 18 laws; pass Utility, Identity and Truth gates. |
| PRODUCT | Solve one clear problem and keep intelligence local to the product. |
| TRUTH | State assumptions and limits; add sources only when real. |
| UX | Test keyboard, mobile, light/dark, empty and error states. |
| DISCOVERY | Use accurate family, tags, related content and internal links. |
| BRAND | Keep it useful, visual and unmistakably Khizooology. |
| PRIVACY | Keep tool data in-browser; preserve opt-in analytics. |
| SHARE | Share only public page/result metadata, never private inputs. |
| VERIFY | Build, relevant audits and a focused browser check pass. |

Final decision: **BUILD**, **IMPROVE**, **REJECT**, or **PUBLISH**.
